# Telas do sistema (protótipo visual)

- `Telas_Observatorio_PI.pdf`: capa, visão geral e todas as telas no tamanho real.
- `svg/`: cada tela em SVG editável (textos, caixas e cores separados em camadas).
- `png/`: imagens das telas em alta resolução.

## Como abrir no Figma
1. Crie ou abra um arquivo de design no Figma.
2. Arraste o arquivo `.svg` da tela para dentro do canvas (ou use **Arquivo → Importar**).
3. Cada texto e cada caixa vira uma camada que pode ser editada.

Para o texto aparecer igual, as fontes usadas são **Inter** e **JetBrains Mono** (as duas já estão disponíveis no Figma).

| Arquivo | Tela |
|---|---|
| 01-cadastro-identificacao | Etapa 1 — Identificação do titular |
| 02-cadastro-descricao | Etapa 1 — Descrição do projeto (com palavras-chave opcionais) |
| 03-verificacao-em-andamento | Janela de verificação em andamento |
| 04-resultado | Etapa 2 — Resultado |
| 05-cadastro-descricao-escuro | Etapa 1 — Descrição (tema escuro) |
| 06-resultado-escuro | Etapa 2 — Resultado (tema escuro) |
| 07-celular-descricao | Celular — Descrição do projeto |
| 08-celular-resultado | Celular — Resultado |

Os dados que aparecem nas telas (nomes, CPF, projeto e resultados de busca) são exemplos fictícios, usados só para demonstrar a interface.
